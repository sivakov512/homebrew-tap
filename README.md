# homebrew-tap

[Homebrew](https://brew.sh) tap for [sivakov512](https://github.com/sivakov512)'s
open-source projects. Formulae here are bumped by each project's release
workflow, so they always point at the latest GitHub release.

No `brew tap` needed, install by the full name:

```sh
brew install sivakov512/tap/kiadopt
```

## What's inside

| Formula | What it is |
|---------|------------|
| [`kiadopt`](Formula/kiadopt.rb) | [kiadopt](https://github.com/sivakov512/kiadopt) — copies parts from KiCad 10 libraries into the project library and relinks the schematic and board. |
